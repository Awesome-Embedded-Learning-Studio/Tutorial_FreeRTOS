# 核心教程

本卷对齐《Mastering the FreeRTOS Kernel》13 章顺序，在主机模拟环境下逐个讲透 FreeRTOS 内核原语。

## 排序铁律

按照左侧侧边栏的数字顺序阅读。两个贯穿全卷的排序约定：

- **内存在任务之前**：先理解堆管理（`heap_1` ~ `heap_5`），再看任务如何分配栈
- **信号量归中断章、互斥量归资源管理章**：二值/计数信号量在中断同步语境讲，互斥量在优先级继承语境讲

## 贯穿项目

[多任务传感器仪表盘](./14_project-dashboard/) 作为渐进式脊柱：采集任务 → 队列 → 处理任务 → 显示任务，每章引入一个原语，最终拼成完整应用。

## 双层 demo 结构

每个示例提供 `mainCREATE_SIMPLE_BLINKY_DEMO_ONLY` 编译开关，可在最小 blinky 与完整 demo 间切换。

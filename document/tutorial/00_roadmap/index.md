# 学习路线图

欢迎。这一页是整套教程的地图——告诉你它长什么样、该怎么用、按什么顺序读,以及那个贯穿全教程的「仪表盘」工程是怎么回事。花两分钟读完它,后面就不会迷路。

## 这套教程长什么样

这是一套**无硬件主机模拟的 FreeRTOS 教程**。意思是:你不需要任何开发板,在你 PC(Linux、macOS、WSL2)上就能把全部 FreeRTOS 内核示例跑起来。我们用 FreeRTOS 官方的 POSIX port 把这个内核搬到你电脑上当普通进程跑,代价是**时序不可信**(详见教学边界),换来的是零硬件门槛、`git clone` 即跑。

教程结构对齐《Mastering the FreeRTOS Kernel》的章节顺序,有一条排序铁律贯穿:**内存在任务之前**(因为任务的栈和 TCB 都是从堆里分配的);**信号量归中断章、互斥量归资源管理章**。

## 怎么用这套教程

每一章都是「概念讲解 + 可运行 demo + 进阶集成」三位一体。建议你这么用:先把正文读完理解机制,然后照着章节里的命令把对应的 demo 在自己机器上 build、跑、改——**亲手跑一遍比读十遍都管用**。每个技术章在仓库的 `code/0X_xxx/` 里都有一个独立的可运行 demo(专讲那一个原语),另外所有原语还会逐步汇入一个贯穿全教程的 `code/dashboard/` 仪表盘工程(下面单独讲)。

先把环境搭好是前提,见 [02 环境搭建](../02_environment/)——只要你能在 PC 上跑出那个 blinky,后面所有章节的 demo 你都能跑。

## 贯穿全教程的 dashboard 仪表盘

`code/dashboard/` 不是某个章节的孤立示例,而是一个**贯穿全教程、逐步生长的工程**——一个多任务传感器仪表盘。它的起点是[环境章](../02_environment/)之后的一个最小骨架(一个心跳任务),然后每学一个原语,就往这个工程里加一块:

```
心跳骨架 →[03]+内存监控 →[04]拆成 sensor+display 两任务
  →[05]队列串起 sensor→display →[06]定时器驱动采样
  →[07]模拟中断经信号量 →[08]mutex 保护共享资源
  →[09]事件组等组合条件 →[10]任务通知 →[12]运行时统计
  →[14]最终集成:采集→队列→处理→显示 的完整应用
```

这样做的好处是:你学的每个原语都不只是孤立 API,而是能立刻看到它在一个真实工程里怎么用、和别的原语怎么配合。等走到 [14 章](../14_project-dashboard/),你已经亲手拼出了一个完整的多任务应用——那既是复习,也是成果。

## 教学边界(一句话)

我们专注教 **FreeRTOS 内核机制**(调度/同步/通信/内存/调试),这些在 host 模拟和真 MCU 上行为一致;**实时性、中断延迟、功耗**明确划在边界外(host 模拟测不出、也教不了),仿真与真 MCU 的差异收在[坑点章](../../pitfalls/)。完整论述见 [01 为什么需要 RTOS](../01_why-rtos/) 的「教学边界」一节。

# D2：核心教程内容

> 15 章正文，顺序对齐《Mastering the FreeRTOS Kernel》。排序铁律：**内存在任务之前；信号量归中断章、互斥量归资源管理章**。

**优先级分布**：

| P0 | P1 | P2 | 总计 |
|----|----|----| ---- |
| 2 | 7 | 5 | 14 |

---

## P0

### [P0] 开篇定位章 + 学习路线图

- **来源**：PLAN task 4
- **描述**：`01_why-rtos` 讲无硬件主机模拟的差异化定位 + **明确教学边界**（专注内核机制，实时性 / 中断延迟 / 功耗声明为边界外）；`00_roadmap` 给出双轨结构与章节脉络
- **涉及**：`document/tutorial/00_roadmap/`、`document/tutorial/01_why-rtos/`

### [P0] 环境搭建章

- **来源**：PLAN task 1
- **描述**：`02_environment` 双轨搭建、harness、编译开关、即时排障。与 D1 的代码产出对接
- **涉及**：`document/tutorial/02_environment/`

---

## P1

### [P1] 堆内存管理（03_memory）

- **描述**：`heap_1` ~ `heap_5` 五种实现对比与选型
- **排序注意**：先讲内存再讲任务（任务栈依赖堆）

### [P1] 任务管理（04_tasks）

- **描述**：创建 / 删除 / 优先级 / 状态的完整生命周期

### [P1] 队列管理（05_queues）

- **描述**：数据传递与解耦的核心原语

### [P1] 软件定时器（06_timers）

- **描述**：单次 / 周期定时器的回调模型

### [P1] 中断管理（07_interrupts）

- **描述**：中断同步，**含二值 / 计数信号量**与延迟中断处理
- **排序注意**：信号量在本章讲，不在资源管理章

### [P1] 资源管理（08_resources）

- **描述**：互斥量、**优先级继承**与死锁预防
- **排序注意**：互斥量在本章讲，不在中断章

### [P1] 项目实战：多任务传感器仪表盘（14_project-dashboard）

- **描述**：渐进式拼装，每章引入的原语在此集成。贯穿全教程的脊柱

## P2

### [P2] 事件组（09_event-groups）

- **描述**：多事件同步与位运算等待

### [P2] 任务通知（10_task-notifications）

- **描述**：轻量级单点通信原语

### [P2] 低功耗（11_low-power）

- **描述**：Tickless Idle 与功耗优化（可选；主机模拟下意义有限，需标注边界）

- **描述**：断言、栈溢出检测（注意 POSIX port 失效）、GDB 技巧（忽略 `SIGUSR1` / `SIG34`）

### [P2] 排错（13_troubleshooting）

- **描述**：常见问题与陷阱速查
